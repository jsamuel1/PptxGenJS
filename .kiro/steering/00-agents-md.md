All agent guidance for this repository lives in the repo-root `AGENTS.md` —
read it first, every session. It binds you to the project Goals, the
canonical conventions (CONTRIBUTING.md / TESTING.md, and RELEASING.md where
present), the architecture decision register (`docs/architecture/decisions/`
— re-proposing a superseded direction is an intent deviation), and the shared
work queue (`PROMPT.md` + `autoloop task list`). The verification gate
applies to every tool: a test run passes if and only if the command exits 0.
