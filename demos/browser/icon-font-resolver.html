Dynamic Icon-Font Resolver

Demonstrates resolveIconFonts(html, opts) — turning the icon-font classes used in HTML (Font Awesome, Material Icons, Bootstrap Icons, Ionicons, Phosphor, or a custom font) into vector SvgPart[] ready for slide.addCard({ icon: { parts } }).

Resolution order (first hit wins, shown per icon): custom css-content font-file cdn bundled. This in-browser demo uses CSS ::before reading + CDN fetch + a small bundled map (font-file outline extraction is Node-only).
